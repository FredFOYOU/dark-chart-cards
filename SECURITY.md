# Sécurité

Ce projet est une galerie front-end sans serveur ni données réelles. Seule la branche `fix/video-fidelity` reçoit des correctifs.

Pour signaler une faille, utilisez le [signalement privé de GitHub](https://github.com/FredFOYOU/dark-chart-cards/security/advisories/new) plutôt qu'une issue publique.
