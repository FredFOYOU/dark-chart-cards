# dark-chart-cards

Reproduction d'une galerie de 10 cartes de graphiques en thème sombre, avec survol synchronisé, compteurs animés et changement de période.

Cette branche, `master`, contient la version construite d'après le brief écrit. La branche [`fix/video-fidelity`](https://github.com/FredFOYOU/dark-chart-cards/tree/fix/video-fidelity) contient la version alignée sur la vidéo de référence.

**Stack :** React 18, TypeScript, Vite, Tailwind CSS, Recharts, Radix UI et Motion.

```bash
npm install
npm run dev
```
